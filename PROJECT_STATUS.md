## 🎯 To Start Using:

### Option 1: Automated (Recommended)
```bash
# Terminal 1
start-backend.bat    # or ./start-backend.sh

# Terminal 2  
start-frontend.bat   # or ./start-frontend.sh

# Browser
http://localhost:3000
```

### Option 2: Manual
```bash
# Backend
cd backend
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate
pip install -r requirements.txt
python init_db.py
uvicorn app.main:app --reload

# Frontend
npm install
npm run dev
```
